# Prácticas de Pruebas e Implementación asis22k26

Repositorio de prácticas de pruebas e implementación basado en el código del proyecto de Análisis de Sistemas II.

Cada pull request ejecuta la validación `Validar proyecto` (`.github/workflows/validacion.yml`), que revisa los archivos modificados en tres frentes: estandarización (prefijos `Cls`/`Frm`, campos `_Campo`, comentarios de autor), código (llaves, conflictos de merge, archivos registrados en el `.csproj`) y separación de capas del modelo MVC.
